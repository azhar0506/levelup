What Serverless is:
- Serverless still used servers
- Servers are managed by the provider
- No server maintenance or OS management
- Infrastructure decisions abstracted away
- Focus is on Code, not servers

Core Characteristics
- Event-driven execution
- Code runs only when triggered
- Billed per execution resource usage
- Built-in autoscaling
- Supports scale to zero
- Provider handles concurrency

Serverless Model
- Typically Function as a Service (FaaS)
- Code deployed as:
	- Zip files
	- Container images
- Runs at any scale automatically


Example: AWS Lambda
- Event-driven execution
- Automatic scaling
- Pay only when code runs
- Concurrency handled by platform (handles multiple requests)
- Supports provisioned concurrency if needed


Cloud Native serverless
- Serverless can run on Kubernetes
- Open-source platforms:
	- Knative
	- OpenFaaS
- Applications can:
	- Scale up demand
	- Scale down when idle
	- Automatically expose service


Challenges
- Provider specific implementations
- Lack of standard API across platforms
- Potential portability issues

CloudEvents
- Standard for describing event data
- Works across across platforms
- Hosted by Cloud Native Computing Foundation
- SDKs available for major language
