### What is the key benefit of using Kubernetes Namespaces?

Isolating resources and limiting the scope of user privileges. Namespaces allow administrators to create multiple virtual clusters wihtin a physical cluster, each with its own set resources (such as pods, services, and secrets). This enables fine-grained control over resource allocation and access, ensuring that users only have access to the resources they need to perform their tasks.

### How can you describe a namespace within a Kubernetes cluster?

Can be thought of as a virtual cluster within the larger Kubernetes cluster. It provides a way to logically sperate and organise resources, such as pods, services, and secrets, into distinct environments. This enables administrators to isolate resources and limit the scope of user privileges, improving security and simplifying resource management.

### Which command is used to view all resources within all namespaces in a Kubernetes cluster?

`kubectl get all -A` is used to view all resources within all namespaces in a Kubernetes cluster. The `-A` flag stands for `--all-namespaces`, which tells kubectl to retrieve information from all namespaces, not just the current one.

### What is the purpose of the `kube-system` namespace in Kubernetes?

Specifically designed to hold objects created by the Kubernetes system, such as system pods, services, and deployments that manage the cluster's infrastructure. These objects are typically not user facing and are instead used internally by the Kubernetes system to manage the cluster.

### If you run a command without specifying a namespace in Kubernetes, which namespace will it run in?

Default. This is because the default namespace is the namespace that is used when no other namespace is specified

### How can a namespace be created in Kubernetes?

```sh
kubectl create namespace mynamespace
```

### How can you run a pod in a specific namespace in Kubernetes?

```sh
kubectl -n mynamespace run pod
```

### Which namespace is readable by all users, including those who are not authenticated?

```sh
kube-public
```

### How can you delete a pod named `nginx` in a specific namespace called mynamespace in Kubernetes?

```sh
kubectl -n my namespace delete pod/nginx
```

### What are the default namespaces provided with a standard Kubernetes installation?

- default
- kube-system
- kube-public
- kube-node-lease

### If a resource in "Namespaced" in Kubernetes, what does this mean?

It means that it is tied to a particular Namespace and exists within the context of that Namespace. This allows for multiple resources with the same name to coexist in different namespaces, without conflicting with eacn other. For example you can have apod named "my-pod" in both "dev" and "prod" namespaces

### What command will change the current context to use a specific namespace?

```sh
kubectl config set-context --curent --namespace=mynamespace
```

### What will happen to the resources inside a namespace if the namespace is deleted in Kubernetes?

When a namespace is deleted in Kubernetes, all the resources wihin that namespace are also deleted. This includes pods, services, deployments, and any other resource that was created within the namespace. This behaviour ensures that deleting a namespace effectively cleans up all associated resources, preventing orphaned or abandoned objects from remaining in the cluster.
