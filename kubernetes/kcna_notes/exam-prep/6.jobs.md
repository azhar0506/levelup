### What occurs in a Kubernetes clsuter when a CronJob is scheduled to run?

The CronJob controller creates a Job resource. The Job controller then manages that Job, ensuring that a Pod is created and run to perform the defined task. The seperation of responsibilities ensures reliability and better control over execution

### What is the primary function of a Job in Kubernetes?

Its designed for batch processing tasks that run to completion, such as data backups or report generation. A Job creates one or more Pods and ensures that a specified number of them successfully terminate, indicating the job has been completed

### Which command is used to create a Kubernetes job named "calculateapi"?

`kubectl create job calculateapi` 

### In a Kubernetes Job, what does the parameter `completions: 20` signify?

Kubernetes will create up to 20 pods overall to complete the task. The Job controller will ensure that at least one pod completes successfully for the job to be considered complete

### What does the parameter `parallelism: 5` signify in a Kubernetes Job specification?

It defines the maximum number of pods that should be running in parallel at any given time. By setting this parameter, you can control the level of concurrency for your job.

### What deos the `kubectl explain job.spec` command do?

Provides detailed documentation fo rthe structure and field of a kubernetes resource, in this case, a Job specification.

### What are CronJobs in Kubernetes?

They are time-based job schedulers. You can specify a schedule using the standard cron syntax.

### What does a CronJob create according to the schedule?

A CronJob creates new Job objects according to its specified schedule. Each time a CtonJob runs, it generates a new Job object that then triggers the creation of Pods to perform the actual work defined within the Job.

### How many completed and failed jobs are kept by default according to the successfulJobsHistoryLimit field in a CronJob?

3

### When a CronJob is deleted, what happens to the associated jobs and pods?

It terminates all the jobs that were triggered by that CronJob, which in turn causes the pods running those jobs to also terminate. The deletion of a CronJob effectively cleans up its associated resoruce (jobs and pods), ensuring they are not left running indefinitely
