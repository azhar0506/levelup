### What is the primary function of a ConfigMap in Kubernetes pod configuration?

Designed to provide non-sensitive configuration data to pods, which can be consumed as environemnt variables or as files in volume

### Write a Kubernetes ConfigMap with values

```sh
kubectl create configmap colour-configmap --from-literal=COLOUR-red --from-literal=KEY=value
```

### How can you check a Kubernetes ConfigMap's values?

```sh
kubectl describe configmap/colour-configmap
```

### What command is used to create a ConfigMap in Kubernetes from a file containing key-value entries?

```sh
kubectl create configmap colour-configmap --from-env-file=configmap-colour.properties
```

### How can a pod be configured to use a ConfigMap's values?

The `envFrom` field in a pod's YAML specificaiton allows you to populate the environment variables of a container with values from a ConfigMap or Secret. When you use `envFrom`, Kubernetes will automatically inject the values from the referenced ConfigMap into the container's environment variables, making them available for your application to use.

### What happens when you set a Kubernetes ConfigMap as 'immutable'?

This would mean that the ConfigMap cannot be changed once it has been created. Any attempts to update or patch an immutable ConfigMap will result in an error? This feature provides a way to ensure that certain configuration data remains unchanged, which can be useful for security and compliance purposes

### What is a significant advantage of using ConfigMaps in Kubernetes?

ConfigMaps in Kubernetes provide a centralised location for storing and managing configuration data that can be used by multiple pods and containers within the cluster. This allows for easier management and updating of application configurations, as well as improved scalability and flexibility.
