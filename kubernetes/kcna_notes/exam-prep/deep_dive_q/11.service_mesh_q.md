### What are the two main components of a Service Mesh?

Data Plane and Control Plane. The Data Plane is responsible for handling network traffic between services, twhile the Control Plane manages and configures the behavior of the proxies in the Data Plane.

### What pattern is commonly used in the Data Plane of a Service Mesh?

The Sidecar pattern is commonly used in the Data Plane of a Service Mesh because it allows for a seperate container or process to run alongside the main applciaiton, providing additional functionality such as traffic management and security. This pattern enables the injection of additional capabilities in to the data path without modifying the applicaiton code.

### What is one of the key security features provided by a Service Mesh?

Mutual TLS - enabling secure communication between microservices by authenticating both the client and server. It ensures that only authrised services can communicate with each other, reducing the risk of unauthorised access or man-in-the-middle attacks

### What does SMI stand for in the context of Service Meshes?

Service Mesh Interface


### What is the primary goal of the Service Mesh Interface (SMI)

To offer a common, interoperable interface for vairous service mesh solutions
