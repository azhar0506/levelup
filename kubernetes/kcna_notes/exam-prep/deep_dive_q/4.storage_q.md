### What is the primary characteristic of ephemeral storage in Kubernetes?

Disigned to providce temporary storage for containers and pods. It doesn not survive across restarts, meaning that if a container or pod is restarted, the data stored in ephermeal storage will be lost

### In the context of Kubernetes, what is an example of ephemeral storage?

emptyDir - its a type of volume that is created when a pod is created and is deleted when the pod is deleted. The data stoed in an emptyDir volume is lost whern the pod is terminalted or restarted.

### What is the primary purpose of a Persistent Volume (PV) in Kubernetes?

Store data that persists beyond the lifecycke if a pod. PVs are designed to provide durable storage for data that needs to be preserved, even if the pod using it is deleted or recreated.

### What does the Reclaim Policy 'Retain' imply in Kubernetes storage?

When a PersistentVolumeClaim is deleted, the PersistentVolume is retained in a 'Released' state with all data intact, and an administrator must manually delete the volume to reclaim the storage resource

### How is a PeristentVolumeClaim (PVC) in Kubernetes typically used?

Used to claim storage resources defined by a PersistentVolume. A PVC is a request for storage resources that can be fulfilled by a PersistentVolume, which is a resource that represents a piece of networked storage. By creating a PVC, a user can request a specific amount and type of storage, which can then be bound to a PersistentVolume that meets the requested criteria

### In Kubernetes, what is the significance of setting a volume's emptyDir.medium to Memory?

Setting emptyDir.medium to Memory configures the volume as a high-perofmrance cache area by sotring its content in the node's RAM instead of disk storage. This allows for faster access and lower latency, making it suitable for caching ro other use cases that require low-latency data access.

### What happens to a Kubernetes PersistentVolume with a Reclaim Policy of 'Delete' after its associated PVC is deleted?

When its associated PVC is deleted, the underlying storage associated with the PersistentVolume will also be delted. This ensures that senstitive data is properly cleaned up and not left behind.

### How is dynamic provisioning of storage in Kubernetes different from manual provisioning?

Dynamic provisioning of storage allows for automatic creation of volumes when a Persistent Volume Claim (PVC) is made. A PVC is a request for storage resources that can be fulfilled by a PV. When a PVC is created, the Kubernetes system automatically provisions a new volume using a StorageClass if one is specified in the claim.
