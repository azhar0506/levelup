### What is the primary difference between Deployments and StatefulSets in Kubernetes?

StatefulSets in Kubenretes provide a sticky identity for each pod, which means that each pod has a unique and persistent identity that is maintained even if the pod is restarted or rescheduled. This is particularly useful for stateful aplications where the identity of the pod is important

### Which of the following is a key characteristic of a StatefulSet in Kubernetes?

it provides each pods with a unique, stable hostname based on the ordinal index and persistent storage volumes that are retained even when pods are rescheduled, which is essential for stateful applications like databases

### When a StatefulSet is used in Kubernetes, how does each pod manage its storage?

Each pod creates its own Persistent Volume Claim to manage its storage. This allows each pod to have its own persistent sotrage that is decoupled from the pod's lifecycle, ensuring that data is repserved even if the pod is deleted or recreated.

### What is the purpose of the 'serviceName' in a StatefulSet's configuration?

Used to define a headless service for network identity, A headless service is a special type of service that doesn't have an IP address or port associated with it. Instead, it provides a way to acccess the pods in the StatefulSet using DNS. By defining a serviceName, you can create a stable network identity for the StatefulSet, which allows other components in your applicaiton to communicate with it reliably.

### What happens to the data volume if a pod in a StatefulSet is deleted and recreated?

In Kuebrentes StatefulSets, each pod has associated PersistentVolumeClaims that persist indepenedently of the pod's lifecycle; when a pod is recreated, the StatefulSet controller reattaches the same claim to the new pod, ensuring data persistence.

### What is a key benefit of using StatefulSets for stateful applications in Kubernetes?

StatefulSets provide stable network IDs for each pod, which means that each pod in a StatefulSwet has a predictable DNS name and hostname. This allows for stable communciation between pods in the same StatefulSet, even if they are rescheduled or recreated.

### In a StatefulSet's updateStrategy, what is the purpose of the 'partition' value?

The partition value indicates the starting point for a rolling update, specifying which pods should be updated first. By setting the partition value to a specific number, you can control which subet of pods are updated initially, allowing for mroe fine-grained control over the rollout process.

### How are pods in a Kubernetes StatefulSet named?
