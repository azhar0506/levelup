# Namespaces

- Divide cluster resources between multiple users and applications
- Isolation
- Resource management - Use of ResourceQuotas
    - allows us to set budgets on how much of a resource such as Memory or CPU can be used by all pods within a namespace
- Resource management - Use of LimitRanges
    - allows us to set the amount of resoruce that each pod or container can use
- Security and Access Control - Integration with RBAC
    - In Kubernetes we can tie TBAC to a particulat namespace - only allowing specifc users/groups and accounts to access the resources within that namespace
- Organisation and Simplification - Integration with RBAC
    - Namespaces amke it easy to manage and organise resources within a large Kubernetes cluster. This is essential when working with Kubernetes clusters in large organisations.

Let's remove this pod

```sh
kubectl delete pod/nginx --now
```

We'll create our own namespace called mynamespace

```sh
kubectl create namespace mynamespace
```

Output:

```sh
namespace/mynamespace created
```

If we wanted to use this namespace, we could add the -n parameter, for example creating an nginx pod

```sh
kubectl -n mynamespace run nginx --image=nginx
```

If we query all available resources, we will see this pod assigned to the our namespace

```sh
kubectl -n mynamespace get pods
```

Output:

```sh
NAME    READY   STATUS    RESTARTS   AGE
nginx   1/1     Running   0          3m32s
```

Running kubectl config view will show the current kubectl configuration, you will see that our default context is using the default namespace, either with a defined key set to default or no key present

```sh
kubectl config view
```

If we desire, we can update our kubernetes server configuration to use a specific namespace

```sh
kubectl config set-context --current --namespace=mynamespace
```

Output:

```sh
Context "default" modified.
```

If we re-check our configuration this will have now changed

```sh
kubectl config view
```

Output:



Let's revert our configuration back to the default namespace

```sh
kubectl config set-context --current --namespace=default
```

And we will remove the mynamespace namespace which in turn, will also remove the nginx pod in the mynamespace namespace

```sh
kubectl delete namespace/mynamespace --now
```

Output:

