### Labels

- Fundeamental for identifying and organising resources
- Effective mechanism for assigning metadata to a Kubernetes Object
- Useful for tagging resources
- Group related resources together
- Kubernetes uses labels and label selectors for service discovery. load balancing, and network policies
- Network policies can use label selectors to define rules for how pods can communicate with each other
- Labels can also be used to create scopes or environments within a Kubernetes cluster
- You could use labels to designate resources as belonging to a certain group (dev, test, prod)
